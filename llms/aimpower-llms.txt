# Brainsuite.ai (formerly aimpower GmbH)

> Brainsuite.ai GmbH builds Brainsuite, an AI creative-effectiveness platform that predicts how an
> advertising asset will perform before any media budget is committed. Founded in 2020 in Hamburg as
> aimpower GmbH and now registered at Kuddewoerde, Germany, the company scores video, static,
> packaging, shelf, out-of-home, digital-banner and social-media creative against an ACE (Advertising
> Creative Effectiveness) score built on applied consumer neuroscience, with effectiveness pillars for
> attention, persuasion, strategic fit, processing ease, emotional engagement and branding.

Generated by API Evangelist (https://apievangelist.com) on 2026-09-14 from the company's public
surface. This is an independent third-party profile, not a Brainsuite publication.

IMPORTANT FOR AGENTS: Brainsuite operates a production API, but publishes no machine-readable
contract for it. There is no OpenAPI, no GraphQL schema, no AsyncAPI, no MCP server, no agent card,
no SDK and no public API reference. Every path on the API host answers HTTP 401. You cannot call this
API from a published contract; access requires a partner or sales conversation, after which the
provider issues credentials together with private documentation.

## API

- [Brainsuite Creative Effectiveness API](https://brainsuite.ai/en/creative-effectiveness-api/):
  Programmatic access to the same AI evaluation engine behind the Brainsuite application. Upload
  assets or supply asset URLs, declare attributes such as brand, market and channel, and receive ACE
  reports with effectiveness scores across tailored KPIs. Positioned for embedding into digital asset
  management systems, creative production tools, generative-AI platforms, ad-tech and activation
  stacks, and creator networks.
- Base URL: https://api.brainsuite.ai/brainsuite (stated by the provider's own runtime configuration
  document as brainsuitePublicApiBaseUrl)
- Access: request API credentials and documentation from the company. No self-service key issuance.
- Pricing: usage-based, with pre-commitments and inclusive volumes. No rates published.

## Authentication

- Platform sign-in is OpenID Connect against an Amazon Cognito user pool the company operates in
  eu-central-1, with its own authorization-server domain at https://auth.brainsuite.ai
- Discovery document (HTTP 200, anonymous):
  https://cognito-idp.eu-central-1.amazonaws.com/eu-central-1_i8L26ssHB/.well-known/openid-configuration
- Scopes advertised: openid, email, phone, profile. No product or resource scopes are published.
- Enterprise single sign-on can be integrated; it is a plan entitlement from Advanced upward.
- The Creative Effectiveness API's own credential scheme is not published.

## Trust and data protection

- [Trust centre](https://trust.brainsuite.ai/) - Vanta-operated. Certifications render client-side
  and could not be read anonymously, so none are recorded here.
- [Data protection](https://brainsuite.ai/en/data-protection/) - GDPR; external Data Protection
  Officer heyData GmbH, Berlin.
- Hosting: AWS eu-central-1 (Frankfurt), S3 with SSE-S3 server-side encryption, client-specific
  buckets, CloudFront. The company states it does not process end-consumer personally identifiable
  information and does not use customer data to train its AI models.

## What is absent

No OpenAPI or Swagger. No GraphQL. No AsyncAPI or documented webhooks. No MCP server. No A2A agent
card. No security.txt or any /.well-known/ document on a company-controlled host. No SDK on any
package registry. No status page. No versioning or deprecation policy. No published rate limits. No
documented idempotency key, pagination scheme, error envelope or reversal operation.
